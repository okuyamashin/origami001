# お話のジャンル

毎回ゼロから筋を考えると似た話が続きやすいので、先にジャンルを決め、ジャンルが偏らないように話を割り振る。

## ジャンル一覧

ジャンル名（英語）は、ストーリーファイルの `genre` セクションに書く値。全言語で同じ。

| ジャンル名 | ジャンル | 内容 | 例 |
| --- | --- | --- | --- |
| `search` | 探す | なくしたもの、隠れたものを見つける | お月さまが落とした鈴を探す |
| `deliver` | 届ける | 何かを遠くの誰かのもとへ運ぶ | 山の上の巣へ、木の実を届ける |
| `rescue` | 助ける | 困っている誰か、迷子を救う | 霧の中で迷子になった子鹿を母鹿のもとへ帰す |
| `confront` | 立ち向かう | 怪物や大きな相手と向き合い、退ける | 川をせき止める大きな岩の怪物を動かす |
| `protect` | 守る | 嵐や危険から、森や仲間を守る | 近づく嵐をいち早く知らせ、皆を避難させる |
| `build` | 作る・直す | 壊れたものを直す、新しいものを作る | 枯れかけた泉を直し、花を咲かせる |
| `mystery` | 不思議を解く | 不思議な出来事の理由を突き止める | 夜ごと消える星の光の謎を解く |
| `escape` | 抜け出す | 閉じ込められた場所や迷路から出る | 迷路のような洞窟から外へ出る |
| `journey` | 旅する | 見たことのない場所まで行って帰る | 地図の端にある白い山まで行く |

ジャンルを増やすときは、この表に足す。

## 割り振りのルール

1. 1話に主なジャンルを1つ決める。
2. **同じ3匹の順番違いの話では、同じジャンルを選ばない（必ず守る）。**
   - 例：`rabbit-clane-frog` が `search` なら、`clane-frog-rabbit` など同じ3匹のほかの5話は `search` 以外にする。
   - 3匹の順番違いは6話、ジャンルは9つあるので、6話すべてを別のジャンルにできる。
3. 2で選べるジャンルのうち、下の「使用状況」で使われた回数が最も少ないものから選ぶ。
4. 同じジャンルを使うときも、舞台、季節、時間帯、小道具を前の話と変える。

## 使用状況

話を追加したら、この表に1行足す。

| --- | --- | --- |

| `clane-frog-rabbit` | `rescue` | きりの朝の子鹿 |
