# おりがみアプリ：構想と紙芝居制作の経緯

記録日：2026年10月8日  
作業先：[okuyamashin/origami001](https://github.com/okuyamashin/origami001)

このドキュメントは、子供向けのおりがみアプリについての会話を、構想、検討の経緯、採用した表現方針、現在の制作内容に整理したものです。提案段階の事項と、実装済みの事項を混同しないため、未決定事項も末尾に記載します。

## 1. アプリの基本構想

子供が折る動物のおりがみと、その動物が冒険する紙芝居を組み合わせる。

- おりがみは将来9種類程度までを想定する。
- その中から3種類を、順番をつけて選ぶ。
- 選んだ動物と順番に対応する冒険物語を、5枚の紙芝居で見せる。
- 物語と絵は、あらかじめAIで制作しておく。
- 物語の中の動物は、折り紙の造形ではなく、生きた普通の動物として描く。
- 最小構成は、うさぎ・鶴・蛙の3種類とする。

同じ種類を重複して選ばない前提では、3種類なら3!＝6通り、9種類なら9×8×7＝504通りとなる。1話5枚を個別に用意する場合、前者は30枚、後者は2,520枚に相当する。これは制作規模の試算であり、現在すべての話が制作済みという意味ではない。

## 2. 物語の構成と広がり

紙芝居の基本構成は次のとおり。

| 枚 | 役割 |
| --- | --- |
| 1 | 3匹が集まり、冒険に出発するオープニング |
| 2 | 最初に選んだ動物が活躍する |
| 3 | 2番目に選んだ動物が活躍する |
| 4 | 3番目に選んだ動物が活躍する |
| 5 | 冒険の結末 |

選択順は、単に画像を並べ替えるためのものではなく、その順番で行動がつながり、結末に届く物語を作るためのものとして考えた。

冒険の目的や舞台、小道具は、話ごとに変えてよい。今回の鈴や森を、全話に共通する要素にする必要はない。何かと戦う話、探す話、届ける話、助ける話、何かを作る話、不思議な現象を扱う話など、幅を持たせる。

静かに音が鳴る結末も、怪物と向き合う冒険も候補となる。動物の活躍も、うさぎは耳、鶴は飛行、蛙は水泳という能力だけに固定せず、勇気や工夫、他の動物との協力などに広げる案が出た。

## 3. 冒険者をどう扱うか

選ぶ動物とは別に冒険者を用意するか、という検討があった。

会話では、まずは選んだ3匹自身を冒険者として扱う方向で進めた。子供が「自分の折った動物が冒険する」と理解しやすく、5枚という短い構成でも各動物の出番を確保できるためである。

動物は共通の外見や小物で識別できるキャラクターとし、舞台や目的は毎回変える。名前を付ける案も出たが、具体的な名前はまだ決めていない。

今回の3匹の外見は次のとおり。

| 動物 | 外見・小物 |
| --- | --- |
| うさぎ | 白い体、無地の青いスカーフ |
| 鶴 | 丹頂鶴、黄土色の小さな肩掛け鞄 |
| 蛙 | 小さな緑の体、無地の赤いスカーフ |

## 4. 絵の方針が決まるまで

最初に、鈴を持ち帰った蛙をうさぎと鶴が迎える場面を試作した。その後、以下の順に表現を調整した。

1. 子供向けの絵本のような表現で試作。
2. 手描きの水彩画風に変更し、大人が見ても美しい絵を目指した。
3. キャラクターの愛らしさを抑え、無機質に近い、淡々とした表情と姿勢に変更。
4. 水彩画をやめ、ボタニカルアートと動物の博物画を組み合わせた表現に変更。
5. 再利用できる画像生成プロンプトを作り、英語に統一。
6. 場面ごとのプロンプトを用意し、その後、明示的な画像生成依頼に沿って5枚を制作。

「無機質」という要望は、動物を機械や物体にする意味ではなく、笑顔、大きな目、大げさなしぐさなどを抑え、静かな存在感を持たせる方向として具体化した。

### 採用した共通の画風

- 横長3:2。
- 古い植物図譜と自然史の動物画を組み合わせた、精密な線描。
- 細いインクの輪郭線、繊細なクロスハッチング、緻密な色鉛筆の彩色。
- 葉脈、シダ、樹皮、毛、羽などを丁寧に描き分ける。
- 生成りの紙の控えめな質感。
- 植物の緑、黄土色、灰青色、生成りを基調に、赤や青を控えめに添える。
- 子供にも分かりやすく、大人にも鑑賞できる静かな美しさ。
- 自然な動物の体形と比率、小さな目、閉じた口、ほぼ無表情の描写。
- 植物標本を並べる構成ではなく、植物を風景に組み込んだ物語の一場面。

避ける表現は、水彩のにじみ・ぼかし、厚塗り、光沢のあるデジタル塗り、3D表現、大きな瞳、漫画的な顔、赤ちゃんのような体形、大げさな身ぶり。画像内の文字、ラベル、額縁、透かし、署名も入れない。

## 5. 最初の紙芝居：お月さまの鈴

最初に制作した物語は、うさぎ → 鶴 → 蛙の順で活躍し、お月さまの落とした鈴を取り戻す冒険である。「お月さまの鈴」は、この記録で内容を識別するための呼称で、正式な作品タイトルは未決定。

| 枚 | 場面 | 主役・構図 | 内容 |
| --- | --- | --- | --- |
| 1 | 森の入口 | 3匹がいる広い風景 | 朝、大きな樫の木の周りで道が分かれる。3匹が冒険の出発前に立ち止まる。 |
| 2 | うさぎが鈴の音を聞き取る | うさぎだけの大きな横向きの近景 | 湖畔の茂みで耳を澄ませ、葦の向こうから聞こえる音の方向を確かめる。鈴はまだ見えない。 |
| 3 | 鶴が空から鈴を見つける | 鶴だけの広がりのある空中の場面 | 湖の上で翼を広げ、小島の灰色の石に置かれた金色の鈴を発見する。 |
| 4 | 蛙が鈴を持ち帰る | 蛙だけの水面に近い近景 | 島へ泳いで鈴を回収した蛙が、水滴をまとい、鈴を持って岸の苔むした石に上がる。 |
| 5 | お月さまに鈴を返す | 3匹と夜空の静かな風景 | 丘の草地から3匹が三日月を見上げる。鈴は三日月の下の先端に戻っている。 |

鈴は、アーチ状の持ち手と小さな三日月の彫刻を持つ金色の鈴として指定した。月には顔や人間的な特徴を付けない。音は動物の姿勢や場面の意味で伝え、音符や音の波などの記号は描かない。

### 2〜4枚目の構図を変えた理由

当初は中間の場面にも3匹すべてを描くプロンプトだったが、2枚目が最初の入口とほとんど変わらず、各動物の活躍が弱く見えるという指摘があった。

そこで、2〜4枚目は活躍する1匹を大きく描き、ほかの2匹を画面に入れない方針に修正した。

- うさぎ：耳と頭が目立つ、低い視点の近景。体は画面の高さのおよそ3分の2を占める。
- 鶴：翼を広げた全身が画面の幅の大部分を占める空中の場面。下方に小島と鈴を配置する。
- 蛙：水面に近い視点で、全身が画面の高さのおよそ半分を占める近景。足、鈴、水から陸への動きを読み取りやすくする。

1枚目と5枚目は3匹を描く場面として維持した。5枚目については、修正前の構想が好評だったため、その方向を保った。

## 6. プロンプトと画像制作の扱い

画像生成プロンプトは英語で作成する。画風、キャラクター、場面・動作、構図、制約を分け、共通の外見と画風を保ちながら、場面ごとに視点や動作を変える。

会話中には、まず「別の場面については絵ではなくプロンプトを作る」という指示があった。その後、用意したプロンプトを使って画像を作る依頼があり、1〜5枚目を順に制作した。今後も、その時点の依頼に応じてプロンプト作成か画像生成かを判断する。

この文書は会話の要約であり、各場面の英語プロンプト全文や、完成した読み上げ台本を収録したものではない。
