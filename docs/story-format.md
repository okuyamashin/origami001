# ストーリーファイルの書式

紙芝居1話分の文章と、使う画像・動画を1つのファイルに書く。

## 置き場所とファイル名

```
data/<origami>/story_<言語>.md
```

- `<origami>`：選んだおりがみを、選んだ順に `-` でつないだもの。例：`rabbit-clane-frog`
- `<言語>`：言語コード。例：`jp`（日本語）
- 画像・動画は同じディレクトリに置く。全言語で共通。

## おりがみ名

- 半角英小文字。
- 名前に空白が入る場合はアンダースコアにする。例：`paper crane` → `paper_crane`
- 全言語で同じ名前を使う。

## セクション

各セクションは `## <セクション名>` で始める。セクション名は英語で、全言語共通。順番は次のとおり。

| セクション | 内容 |
| --- | --- |
| `origami` | 選んだおりがみ。ディレクトリ名と同じ値を1行で書く。全言語で同じ。 |
| `title` | お話のタイトル。 |
| `description` | お話の説明。 |
| `page_1` 〜 `page_5` | 紙芝居の各ページ。 |

### ページ（`page_1` 〜 `page_5`）

先頭に、使うファイルを `キー: ファイル名` の形で書き、空行のあとに本文を書く。

| キー | 必須 | 内容 |
| --- | --- | --- |
| `image` | 必須 | 画像ファイル名 |
| `video` | 任意 | 動画ファイル名。動画がない場合は行ごと省略する。 |

本文は複数行でよい。行の区切りは、読み上げや表示のときの改行になる。

## 読み上げ用の文（speech）

`title`・`description`・各ページには、本文のあとに `### speech` を付け、音声合成（OpenAI、Amazon Polly など）にそのまま渡せる文を、その言語で書く。

- 本文の1行に対して、speech も1行で書く。行数と順番を本文とそろえる。
- 内容は本文と同じにし、読み間違えにくい表記に直すだけにする。
- `### speech` がない場合は、本文をそのまま読み上げる。

### 日本語の speech の書き方

本文の表記ルール（小学校で習わない漢字はひらがな）は適用しない。読み上げで正しく読まれることを優先する。

- 読みが一つに決まる漢字は使う。ひらがなよりアクセントや区切りが正しくなりやすい。例：つる→鶴、かえる→蛙、すず→鈴
- 読みが揺れる語はひらがなで書く。例：今日→きょう、草地→くさち、金色→きんいろ、音→おと
- 区切りが分かりにくい所には読点を入れる。

## 日本語の表記

小学校で習わない漢字は使わず、ひらがなで書く（例：鶴→つる、蛙→かえる、鈴→すず）。`title` と `description` も同じ。

## 例

```
## origami

rabbit-clane-frog

## title

お月さまのすず

### speech

お月さまの鈴

## description

（お話の説明）

### speech

（お話の説明の読み上げ用の文）

## page_1

image: 1-first.png
video: 1-first.mp4

（1枚目の本文）

### speech

（1枚目の読み上げ用の文）

## page_2

image: 2-rabbit.png

（2枚目の本文）

### speech

（2枚目の読み上げ用の文）
```
