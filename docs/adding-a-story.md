# お話を追加する手順

選んだおりがみの組み合わせ（順番つき）ごとに、紙芝居1話を追加する手順。ファイルの書式は [story-format.md](story-format.md) を参照。

## 1. ディレクトリ名を決める

選ぶ順におりがみ名を `-` でつなぐ。おりがみ名は全話で同じ綴りを使う。

| おりがみ | 名前 |
| --- | --- |
| うさぎ | `rabbit` |
| 鶴 | `clane` |
| 蛙 | `frog` |

例：鶴 → 蛙 → うさぎの順なら `clane-frog-rabbit`。

おりがみの種類を増やすときは、この表に名前を足す。

## 2. ディレクトリとストーリーファイルの雛形を作る

```
data/<ディレクトリ名>/
  story_jp.md
  story_en.md
```

- `origami` セクションにディレクトリ名を書く。
- `genre` は手順3で決めるので、雛形では日本語版は `（未定）`、英語版は `(TBD)` にしておく。
- 各ページの `image:` に画像ファイル名を書く（次の命名規則）。
- まだ決まっていない所は、日本語版は `（未定）`、英語版は `(TBD)` と書いておく。

### 画像ファイル名

| ページ | ファイル名 | 例（`clane-frog-rabbit`） |
| --- | --- | --- |
| 1 | `1-first.png` | `1-first.png` |
| 2 | `2-<1番目のおりがみ名>.png` | `2-clane.png` |
| 3 | `3-<2番目のおりがみ名>.png` | `3-frog.png` |
| 4 | `4-<3番目のおりがみ名>.png` | `4-rabbit.png` |
| 5 | `5-last.png` | `5-last.png` |

## 3. ジャンルと物語の筋を決める

まず [genres.md](genres.md) の割り振りのルールに従ってジャンルを1つ選び、ストーリーファイルの `genre` と、genres.md の「使用状況」に書く。次に、そのジャンルで筋を考える。

5枚の役割は全話共通。

| ページ | 役割 |
| --- | --- |
| 1 | 3匹が集まり、冒険に出発する |
| 2 | 1番目に選んだ動物が活躍する |
| 3 | 2番目に選んだ動物が活躍する |
| 4 | 3番目に選んだ動物が活躍する |
| 5 | 冒険の結末 |

- 選んだ順番で行動がつながり、結末に届く物語にする。順番を入れ替えただけの話にはしない。
- 舞台・季節・時間帯・小道具は話ごとに変える。
- 活躍の仕方は、動物の能力（耳、飛ぶ、泳ぐ）だけに固定せず、勇気や工夫、協力にも広げてよい。
- 動物に名前は付けない。外見と小物（うさぎ：青いスカーフ、鶴：黄土色の肩掛け鞄、蛙：赤いスカーフ）で見分ける。

## 4. 本文を書く

- `title`、`description`、`page_1`〜`page_5` の本文を、日本語版と英語版で書く。
- 日本語版の本文は、小学校で習わない漢字をひらがなにする。
- ページごとの行数は日本語版と英語版でそろえる。

## 5. 読み上げ用の文（speech）を書く

- 各セクションの `### speech` に、音声合成にそのまま渡せる文を書く。
- 書き方は [story-format.md](story-format.md) の「読み上げ用の文（speech）」に従う。

## 6. 画像作成のプロンプトを作る

本文をもとに、各ページの画像を作るためのプロンプトを書く。

- 英語で書く。
- `data/<ディレクトリ名>/prompts.md` に保存する（例：[clane-frog-rabbit/prompts.md](../data/clane-frog-rabbit/prompts.md)）。
- 全ページ共通の部分は `## common` に、`### style`（画風）・`### characters`（キャラクター）・`### constraints`（制約）として書く。
- ページごとの部分は `## page_1`〜`## page_5` に、`### scene`（場面・動作）・`### composition`（構図）として書く。
- 画像を作るときは、common の3つとそのページの2つをつなげて1つのプロンプトにする。
- お話に出てくる3匹以外の動物（子鹿など）も、`### characters` に外見を書いておく。
- 1・5枚目は3匹を描く。2〜4枚目は活躍する1匹だけを大きく描き、ほかの2匹は入れない。
- 画像内に文字、ラベル、額縁、署名を入れないことを制約に書く。

## 7. 画像を作る

- 手順6のプロンプトを使い、ChatGPT で作る。
- 画風は全話共通（[project-history.md](project-history.md) の「採用した共通の画風」）。
- 横長3:2、PNG（既存の画像は 1536×1024）。
- 手順2で決めたファイル名で保存する。
- 本文やプロンプトと合わない画像になったら、プロンプトを直して作り直し、`prompts.md` も更新する。

## 8. 音声を作って確かめる

- 読み上げ方式（OpenAI、Amazon Polly など）は未決定。決まったらここに手順を書く。
- 作った音声を聞き、読み間違えた所は speech を直して作り直す。

## 9. main に反映する

- 作業用ブランチでコミットし、確認してから main に push する。
