# ストーリーファイルの書式

紙芝居1話分の文章と、使う画像・動画を1つのファイルに書く。

## 置き場所とファイル名

```
data/<origami>/story_<言語>.md
```

- `<origami>`：選んだおりがみを、選んだ順に `-` でつないだもの。例：`rabbit-clane-frog`
- `<言語>`：言語コード。例：`jp`（日本語）
- 画像・動画は同じディレクトリに置く。全言語で共通。

## おりがみ名

- 半角英小文字。
- 名前に空白が入る場合はアンダースコアにする。例：`paper crane` → `paper_crane`
- 全言語で同じ名前を使う。

## セクション

各セクションは `## <セクション名>` で始める。セクション名は英語で、全言語共通。順番は次のとおり。

| セクション | 内容 |
| --- | --- |
| `origami` | 選んだおりがみ。ディレクトリ名と同じ値を1行で書く。全言語で同じ。 |
| `title` | お話のタイトル。 |
| `description` | お話の説明。 |
| `page_1` 〜 `page_5` | 紙芝居の各ページ。 |

### ページ（`page_1` 〜 `page_5`）

先頭に、使うファイルを `キー: ファイル名` の形で書き、空行のあとに本文を書く。

| キー | 必須 | 内容 |
| --- | --- | --- |
| `image` | 必須 | 画像ファイル名 |
| `video` | 任意 | 動画ファイル名。動画がない場合は行ごと省略する。 |

本文は複数行でよい。行の区切りは、読み上げや表示のときの改行になる。

## 日本語の表記

小学校で習わない漢字は使わず、ひらがなで書く（例：鶴→つる、蛙→かえる、鈴→すず）。`title` と `description` も同じ。

## 例

```
## origami

rabbit-clane-frog

## title

お月さまの鈴

## description

（お話の説明）

## page_1

image: 1-first.png
video: 1-first.mp4

（1枚目の本文）

## page_2

image: 2-rabbit.png

（2枚目の本文）
```
